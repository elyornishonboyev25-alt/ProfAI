# Writing Full Tests 5–30: Task 1 practice visuals

The [official IELTS Academic Writing format](https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-writing) asks candidates to describe a graph, chart, table or diagram in at least 150 words, spending about 20 minutes. The [official sample tasks](https://ielts.org/take-a-test/preparation-resources/sample-test-questions/academic-test) were used to check the presentation and scope of these practice tasks.

All 26 visuals here are original IELTS-style **practice** SVG images authored for this project. Their numbers and place names are illustrative; they are not official IELTS exam questions or claims about actual populations. Each SVG is stored locally, and its prompt and evaluation context use the same source specification in `src/data/writingFullTestPracticeVisuals.ts`. Run `node scripts/generate-writing-practice-images.mjs` to regenerate the images. `npm run validate:writing` checks every image against the specification.

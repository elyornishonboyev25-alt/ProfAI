# Study objects

`study-objects-transparent.png` is an authored ProfAI UI illustration asset,
generated with the built-in ImageGen tool for this redesign and edited by that
tool to provide real alpha transparency. It is a 1536 × 1024 sprite sheet with a
3 × 2 grid: headphones, book, microphone; calculator, notebook, globe.

Art direction: photoreal product photography, charcoal metal, ivory paper,
restrained burgundy accents, consistent studio lighting. No third-party logos.
`StudyObject.tsx` displays the cells through CSS background positioning.

Only this final production source image is consumed by the application; preview
boards, intermediate generations and QA screenshots are not deployment assets.
